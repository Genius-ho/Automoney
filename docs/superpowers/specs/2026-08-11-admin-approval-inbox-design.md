# 관리자 승인함 설계

## 목적

운영자가 상품 목록과 상세 탭을 여러 단계로 이동하지 않고, 현재 사람이 결정해야 하는 모든 작업을 관리자 첫 화면 한 곳에서 확인하고 처리한다.

## 범위

관리자 화면에 `승인함` 보기를 추가하고 기본 보기로 사용한다. 승인함은 자동 처리 흐름에서 사람의 승인을 기다리는 항목만 보여준다.

- 이미지 승인: 대표 이미지와 상세 이미지 세트
- 쿠팡 판매 승인
- 공급처 발주 승인
- 승인 단계에서 실패해 운영자의 재시도가 필요한 항목

일반 상품 탐색, 전체 자동 선정 이력, 분석 결과 편집 기능은 기존 화면에 유지한다.

## 사용자 경험

### 상단 요약

관리자 접속 시 승인함을 먼저 연다. 상단에는 다음 건수를 표시한다.

- 이미지 승인 N건
- 판매 승인 N건
- 발주 승인 N건
- 처리 실패 N건

건수는 승인함의 실제 카드 수와 일치해야 한다.

### 승인 카드

각 카드는 한 번의 판단에 필요한 정보를 한곳에 표시한다.

- 상품명과 드래프트 ID
- 현재 승인 종류와 처리 상태
- 원가, 판매가, 예상 마진
- 대표 이미지 미리보기
- 상세 이미지 10장 미리보기
- 실패한 경우 오류 메시지

이미지 승인 카드에는 `전체 이미지 승인` 버튼 하나를 제공한다. 이 버튼은 현재 업로드 상태인 대표 이미지와 최신 상세 이미지 세트를 하나의 사용자 동작으로 승인한다. 둘 중 하나라도 승인할 수 없으면 부분 승인하지 않고 오류를 표시한다.

판매 승인과 발주 승인은 각각 기존의 검증 및 승인 서비스를 그대로 호출하는 단일 버튼을 제공한다. 기존 텔레그램 승인 경로와 동일한 상태 전이 규칙을 사용한다.

승인 성공 시 카드는 승인함에서 즉시 제거되고 상단 건수를 갱신한다. 다음 자동 단계가 시작됐다는 짧은 결과 메시지를 표시한다.

### 실패 카드

승인 또는 후속 자동 처리에 실패한 항목은 빨간 상태로 표시한다. 카드에 실패 단계와 오류 메시지를 보여주고, 안전하게 재실행할 수 있는 기존 단계에만 `다시 시도` 버튼을 제공한다. 외부 중복 실행 위험이 있는 작업은 현재 외부 상태를 먼저 조회하는 기존 멱등 처리 경로를 사용한다.

## 구조

### 조회 API

승인함 전용 조회 API가 다음 자료를 서버에서 결합해 반환한다.

- `processing_queue`의 현재 처리 상태와 자동 선정 상품 연결
- 승인되지 않은 생성 대표 이미지와 최신 상세 이미지 세트
- 판매 승인을 기다리는 쿠팡 등록 정보
- 발주 승인을 기다리는 공급처 주문

클라이언트가 전체 상품을 받아 상태를 추론하지 않도록 서버가 카드 종류, 표시 자료, 가능한 동작을 명시한다.

### 승인 API

이미지 일괄 승인은 서버 트랜잭션 안에서 대표 이미지와 상세 이미지 세트의 현재 상태를 다시 검증한 후 함께 승인한다. 승인 완료 후 기존 이미지 승인 후처리 서비스를 호출해 쿠팡 임시 등록과 텔레그램 판매 승인 알림 흐름을 이어간다.

판매 승인과 발주 승인은 새 로직을 복제하지 않고 기존 승인 함수를 호출한다.

### 관리자 UI

기존 관리자 단일 페이지에 `승인함` 보기를 추가한다. 관리자 진입 시 승인함을 기본으로 표시하고, 기존 상품 목록 및 자동 배치 화면은 별도 메뉴로 계속 접근할 수 있게 한다.

승인 버튼은 요청 중 비활성화하여 중복 클릭을 막는다. 성공하면 카드 목록을 다시 불러오고, 실패하면 카드를 유지한 채 서버 오류를 표시한다.

## 오류 처리와 안전성

- 조회 실패 시 빈 승인함으로 오인하지 않고 명시적인 로드 실패 메시지를 표시한다.
- 이미지 일괄 승인은 원자적으로 처리하여 대표 이미지만 승인되는 부분 성공을 방지한다.
- 모든 승인 API는 DB의 현재 상태를 재검증하고 이미 처리된 요청에는 멱등한 결과를 반환한다.
- 외부 쿠팡 등록, 판매 승인, 실제 발주는 기존 안전장치와 검증 절차를 우회하지 않는다.
- 카드의 버튼은 서버가 반환한 `availableActions`에 포함된 동작만 활성화한다.

## 테스트

- 승인함 조회가 이미지·판매·발주·실패 카드를 정확히 분류하는 저장소/API 테스트
- 이미지 일괄 승인의 성공, 상태 불일치, 부분 승인 방지 테스트
- 승인 후 기존 쿠팡 등록 및 텔레그램 알림 서비스가 한 번만 호출되는 테스트
- 관리자 HTML에 승인함 기본 보기, 상단 건수, 단일 승인 버튼, 오류 표시가 렌더링되는 테스트
- 버튼 중복 클릭 방지와 성공 후 카드 제거를 검증하는 UI 수준 테스트
- 전체 테스트 실행 후 로컬 관리자 화면에서 드래프트 118 카드와 이미지 미리보기 및 승인 버튼을 확인하는 수동 검증

## 완료 기준

운영자가 `/admin`을 열자마자 드래프트 118을 포함한 승인 대기 항목을 볼 수 있고, 상품 상세나 이미지 프롬프트 탭으로 이동하지 않은 채 `전체 이미지 승인` 한 번으로 이미지 승인을 완료할 수 있다. 이후 쿠팡 등록 및 텔레그램 판매 승인 흐름은 기존 자동화 규칙에 따라 이어져야 한다.
