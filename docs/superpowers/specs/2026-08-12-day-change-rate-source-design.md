# 보유종목 등락률 기준 데이터 통합 설계

## 목적

무한매수 계좌 보유종목의 등락률을 토스 화면의 실제 등락률과 일치시키고, 한국과 미국의 날짜 차이, 장전·정규장·장후 구간, 일봉 생성 지연, 응답 순서 변경 때문에 다시 틀어지지 않게 한다.

## 현재 문제

현재 서비스는 가격 응답의 `lastPrice`와 별도로 조회한 수정 일봉(`adjusted=true`)을 조합해 등락률을 다시 계산한다. 가장 최신 일봉이 진행 중인 당일 봉이라고 가정하고 그 다음 날짜의 종가를 전일 종가로 선택하기 때문에, 당일 봉이 아직 없으면 이틀 전 종가가 기준이 된다. 반대로 한국 날짜로 당일 여부를 판단하면 미국 정규장 중 최신 봉을 전일 봉으로 오인한다.

또한 잘못 선택된 종가를 한국 달력 날짜 동안 캐시하므로 첫 조회가 틀리면 이후 새로고침에서도 계속 틀린다. 등락률 계산이 `WebService`와 독립형 `DashboardService`에 중복되어 한쪽 수정이 다른 쪽에 반영되지 않는 문제도 있다.

## 데이터 우선순위

1. 가격 API 응답에 토스가 계산한 공식 등락률 필드가 있으면 그 값을 그대로 사용한다.
2. 공식 등락률은 없지만 공식 전일 종가 또는 기준가 필드가 있으면 `(현재가 - 기준가) / 기준가 * 100`으로 계산한다.
3. 두 값이 모두 없을 때만 일봉을 보조 데이터로 사용한다.
4. 어떤 방법으로도 신뢰할 수 있는 기준가를 정할 수 없으면 잘못된 숫자를 표시하지 않고 등락률을 `null`로 반환한다.

가격 API의 실제 필드명 차이를 수용하도록 알려진 별칭을 명시적으로 지원하되, 의미가 불분명한 숫자 필드를 추측해서 사용하지 않는다.

## 일봉 보완 규칙

일봉은 공식 등락률을 얻지 못했을 때만 조회한다. `adjusted=false`로 공식 종가를 요청한다. 가격 응답의 시세 타임스탬프에서 미국 거래 세션 날짜를 얻을 수 있는 경우 그 날짜보다 앞선 가장 최신 일봉을 전일 종가로 선택한다.

시세 타임스탬프가 없으면 최신 일봉이 당일 진행 봉인지 확정할 수 없으므로 두 번째 일봉을 임의 선택하지 않는다. 이 경우 최신 일봉 종가와 현재가가 동일하다는 이유만으로 당일 봉이라고 추정하지 않으며 등락률을 `null`로 둔다.

응답 순서에는 의존하지 않고 타임스탬프의 날짜로 정렬한다. 잘못된 행 하나가 전체 계좌 새로고침을 실패시키지 않도록 누락·형식 오류가 있는 일봉은 제외한다.

## 공용 계산 경계

시세 행과 선택적인 일봉 목록을 입력받아 `current_price`, `previous_close`, `day_change_pct`를 반환하는 작은 공용 모듈을 둔다. 메인 `WebService`와 독립형 `DashboardService`가 모두 이 모듈만 사용한다.

계좌·주문·전략 로직은 변경하지 않는다. 전일 종가는 주문 계획에서도 사용되므로, 화면 등락률과 주문 계획이 동일한 검증된 전일 종가를 공유하게 한다.

## 캐시 정책

가격 응답의 공식 값은 새로고침마다 갱신한다. 일봉 보완 결과는 장기 캐시하지 않는다. API 호출량을 줄여야 한다면 시세의 세션 날짜와 선택된 전일 봉 날짜를 함께 키로 사용하는 짧은 수명 캐시만 허용한다. 이번 수정에서는 정확성을 우선해 기존 한국 달력 날짜 단위 전일 종가 캐시를 제거한다.

## 오류 처리와 표시

- 공식 등락률 값이 숫자가 아니면 기준가 방식으로 내려간다.
- 기준가가 0 이하이면 사용하지 않는다.
- 현재가가 없거나 0 이하이면 등락률은 `null`이다.
- 검증 가능한 기준가가 없으면 `null`을 반환하며 0%로 위장하지 않는다.
- 독립형 대시보드도 모든 보유종목에 같은 규칙으로 `day_change_pct`를 제공한다.

## 테스트 전략

다음 회귀 사례를 테스트로 먼저 작성한다.

- 가격 응답의 공식 등락률이 있으면 일봉 값과 달라도 공식 값을 사용한다.
- 공식 기준가가 있으면 공식 등락률이 없어도 정확히 계산한다.
- 진행 중인 당일 일봉이 있을 때 직전 거래일 종가를 선택한다.
- 장전처럼 당일 일봉이 없을 때 최신 완료 일봉을 전일 종가로 선택한다.
- 한국 날짜와 미국 세션 날짜가 달라도 시세 타임스탬프를 기준으로 선택한다.
- 일봉 순서가 뒤섞여도 결과가 같다.
- 타임스탬프 또는 종가가 잘못된 행은 안전하게 제외한다.
- 신뢰 가능한 기준이 없으면 `null`을 반환한다.
- 메인 서비스와 독립형 대시보드가 동일한 결과를 반환한다.
- 두 번의 새로고침 사이에 세션이 바뀌면 이전 기준가가 남지 않는다.

관련 단위 테스트와 웹 서비스·대시보드 통합 테스트를 실행한 후 전체 테스트 모음을 실행한다.

## 완료 기준

- 동일한 가격 응답에 대해 두 웹 경로의 등락률이 일치한다.
- 토스 가격 응답에 공식 등락률이 있으면 표시값이 그 값과 일치한다.
- 공식 값이 없는 경우에도 거래 세션을 확정할 수 있을 때만 일봉으로 계산한다.
- 재발 조건이 자동화된 테스트로 고정된다.
- 기존 계좌 새로고침, 주문 계획, 자동매매 관련 테스트가 모두 통과한다.
